# 📡 ETD 레이더 (etd-radar)

> 밀린 ETD와 L/C 선적 기한 위험을 한눈에 잡아내는 선적 일정 레이더

**🔗 배포 주소:** (Vercel 배포 후 여기에 주소를 적어 주세요)

## 왜 만들었나
종합상사 신입 해외영업 담당자는 오더 여러 건의 ETD를 선사·포워더 메일로 따로 확인하다 보니,
일정이 밀린 건을 늦게 알아채고 ETD가 밀려 **L/C 선적 기한을 넘기거나 기한 직전에야** 알게 됩니다.
ETD 레이더는 오더별 ETD와 L/C 선적 기한을 한곳에 모아 위험을 먼저 보여 줍니다.

## 기능 (PRD v4.0)
| | 기능 | 핵심 |
|---|---|---|
| F1 | 오더 등록 · 수정 · 목록 | 결제 조건(L/C · T/T · D/P) · 선적항(삼국 간), 선사 · 부킹 · B/L · 서류 마감 · 대응 계획, **수정 시 ETD · L/C 기한 변경은 사유와 함께 기록(L/C 연장)**, 선적 완료와 되돌리기, **인코텀즈 · 지정 장소 · 도착항**(누가 배를 잡는지 표시), **L/C 원본 칸**(44C · 31D · 48 · 44E · 44F), 검색, 숨기기 삭제 · 복구, 달력 입력, **일괄 등록**(CSV 업로드 · 엑셀 붙여넣기 · 빈 양식) |
| F2 | 경고 | 🚨 **ETD 지남 · 선적 미확인**(모든 결제 조건, 가장 먼저) · L/C 여유 일수 🔴 초과 / 🟡 0~7일 / 🔵 8일 이상 · 서류 마감 지남/임박 |
| F3 | 변경 기록 | ETD · L/C 기한 · 상태 변경을 한 표로, 증감은 회색 ▲▼, 선사 조회 **데모** — 요청 → 응답 → 비교 → 반영을 단계별로 보여 주는 시뮬레이션(example.com 가상 주소) |
| F4 | 보고 내보내기 · 불러오기 | 🚨 → 🔴 → 🟡 보고 문장 + **대응 계획**, 엑셀 CSV(한글 안 깨짐) · 표 복사, **CSV 불러오기**(미리보기 · 이미 있는 오더는 건너뜀) |
| F5 | 앱 안 알림 · 일정 캘린더 | 홈 화면 **선적 현황**: 맨 위 월간 캘린더(종류 + 번호 · 바이어, 누르면 요약 창) + 오른쪽 **결정 카드**(바이어 · 품목 · 할 일 · 연락할 곳 · 대응 계획 바로 적기) · 브라우저 탭 제목에 건수 "(6) ETD 레이더" · **월간 캘린더**(ETD · L/C 기한 · 서류 마감 · ETA · 실제 선적, 경고 색 그대로, 누르면 그 오더로, 휴대폰은 다가오는 일정 목록) |
| F6 | 화면 기준 | 휴대폰 카드형 · 목록 6칸 + 펼쳐 보기 · 날짜 "11/20 (금)" 통일 · 색 의미 하나 · 선 아이콘 · 명암비 4.5:1 · 사용 안내 |
| F7 | 입력 크로스체크 | **오류는 저장 막음**: ETA < ETD · 서류 마감 > ETD · L/C 유효기한 < 선적 기한 · L/C 선적 기한 두 번 입력 불일치 / **확인 필요 표시**: 서류 제시 기간 부족(UCP 600 기본 21일) · 44E/44F와 오더 항구 불일치 · 인코텀즈 지정 장소 불일치 · 부킹/B/L 번호 중복 · 날짜 오타 의심 |
| F8 | 메일에서 가져오기 | 선사 · 포워더 메일 **본문 붙여넣기**(Vercel · Claude · Streamlit) 또는 **Gmail에서 바로**(Claude 페이지, 본인 메일 읽기만) → 오더번호 · ETD · ETA · B/L · 선명 찾기 → 바뀔 칸 미리보기 → 확인해야 반영 · 없는 오더는 새 오더 칸 채우기 |

- 임박 기준 7일: 정기선은 주 1회 운항이 많아 **롤오버 한 번에 ETD가 약 1주** 밀리기 때문
- 모든 회사명 · 오더는 **가상 데이터**이며, 선사 조회는 실제 선사와 연결되지 않은 데모입니다.
- 이메일 · 푸시 알림, 여러 사람 실시간 공유는 서버가 필요해 이번 버전에서 하지 않았습니다 (CSV 내보내기 · 불러오기로 옮김).

## AI 직원 팀 (Claude Code 서브에이전트)
| 직원 | 하는 일 | 권한 |

업무 매뉴얼 `/radar-ship` : 기능 고르기 → 만들기 → 직원 3명 검사 → 고치고 재검사 → 출시 표시.

## 폴더 구성
```
PRD.md          기획서 (기능 · 완료 기준 · 하지 않을 것)
CLAUDE.md       회사 규칙 (데이터 보호 · 한국어 에러 · 허락 없이 배포 금지 …)
STAFF.md        직원 설계표
.claude/        서브에이전트 3명 · 업무 매뉴얼 /radar-ship
logic.py        계산 · 입력 검사   storage.py  파일 읽기 · 쓰기
app.py          Streamlit 화면     config.py / messages.py  설정 · 문구
tests/          pytest 테스트 (93개)
data/           가상 데이터 (orders.csv · etd_changes.csv · carrier_demo.json)
web/index.html  배포용 웹 대시보드 (같은 규칙 · 같은 가상 데이터)
```

## 실행
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py     # 로컬 앱
python -m pytest -q                # 테스트
```
웹 대시보드(`web/`)는 정적 페이지라 Vercel에 **Root Directory = `web`** 으로 배포합니다.
